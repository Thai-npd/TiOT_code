# Time-integrated Optimal Transport — Experimental Code

This repository provides the experimental code and data used in the paper “Time-integrated Optimal Transport: A Robust Minimax Framework.”
It includes the scripts needed to reproduce the results and figures presented in the experimental section.

### Requirements
Python 3 with `numpy`, `scipy`, `pandas`, `pot` (Python Optimal Transport), `scikit-learn`, `matplotlib`, `seaborn` and `tqdm`:

    pip install numpy scipy pandas pot scikit-learn matplotlib seaborn tqdm

### Datasets
 - Data for the experiments in Sections 4.1 and 4.3 is synthetically generated by the scripts.
 - Data for Section 4.2 is provided in the file `DailyDelhiClimateTrain.csv`.
 - Data for Section 4.4 comes from the UCR time series classification archive and is stored in the folder `time_series_datasets`, one sub-folder per dataset containing `<Name>_TRAIN.txt` and `<Name>_TEST.txt`.

All 63 datasets of Table 1 are included. To run another dataset of the archive, download `<Name>.zip` from
`https://www.timeseriesclassification.com/aeon-toolkit/<Name>.zip` (for example, https://www.timeseriesclassification.com/aeon-toolkit/Crop.zip)
and extract `<Name>_TRAIN.txt` and `<Name>_TEST.txt` into `time_series_datasets/<Name>/`.

### Code Structure
The main solver for the TiOT and eTiOT problems, along with related components, is implemented in `TiOT_lib.py`.
The experiment scripts correspond to the paper’s sections:
 - `alignment_Exp.py` – Section 4.1 (Figure 2).
 - `lag_series_Exp.py` – Section 4.2 (Figure 3).
    - `dist_lag_exp()` reproduces Figure 3 (left); this is what `python lag_series_Exp.py` runs.
    - `dist_w_exp()` reproduces Figure 3 (right).
 - `runtime_Exp.py` – Section 4.3 (Figure 4). `python runtime_Exp.py` runs both parts:
    - `deviation_experiment()` reproduces Figure 4 (left);
    - `runtime_experiment()` reproduces Figure 4 (right).
 - `kNN_Exp.py` – Section 4.4 (1NN classification, Table 1). For each dataset, `experiment_TiOTselect_kNN(name, w_TAOT, eps_list=[0.01])`
   selects a single weight w* by solving eTiOT on sampled pairs of training series from different classes, then runs 1NN with that fixed w*.
   It also runs eTAOT at the pre-tuned weight `w_TAOT` of the TAOT paper for comparison (pass `w_TAOT=None` to skip it).
   A report per dataset, with test errors and timings, is written to `Experimental_outputs/kNN_data/saved_results/`.
 - `Tools/plot_error_comparison.py` – draws the 1NN error comparison figure of Section 4.4 from the reports that `kNN_Exp.py` writes
   to `Experimental_outputs/kNN_data/saved_results/` and the ED / DTW errors of the UCR archive (`Tools/data/UCR_DataSummary.csv`).
   Run it after `kNN_Exp.py` has produced the reports of all 63 datasets:

       python Tools/plot_error_comparison.py --eq 22

### Running Experiments
Run the scripts from the repository root, for example:

    python lag_series_Exp.py

Experimental outputs are saved in the `Experimental_outputs` directory, in one sub-folder per experiment.
